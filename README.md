# THE REAPING — Capitol Edition (Flat GitHub Pages Package)

All app files and assets are in the ROOT of this folder. No asset subfolders are used.

## Upload to GitHub
1. Extract this ZIP.
2. Open your GitHub repository → Add file → Upload files.
3. Select ALL files inside the extracted folder (not the folder itself).
4. Commit changes to the `main` branch.
5. Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.

Confirm these appear at the top level: index.html, district-1.png through district-5.png, capitol-ambient-bgm.wav, and reaping-reveal.wav.

## Included
Five supplied district emblems, 35 tribute names, district and all-district selection, countdown, reveal effect, looping ambient BGM, history, CSV export, presentation mode, PWA manifest/icons and offline service worker.

## Audio
Tap **Music on** to start the looping ambient background music. Browsers block autoplay until a user interaction. The dramatic reveal sound plays when a tribute is drawn if Effects are enabled.

## PWA
GitHub Pages HTTPS supports installation and service workers. After replacing an older deployment, refresh the site. If old cached files persist, clear the site's data once and reload.
